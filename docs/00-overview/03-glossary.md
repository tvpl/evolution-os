# Glossário

| Termo | Definição no ecossistema |
|---|---|
| Project | Unidade monitorada: ideia, produto, serviço, repositório, harness ou portfólio composto. |
| Project Twin | Representação viva de intenção, decisões, arquitetura, implementação, operação e relações. |
| Evolution Hub | Control Plane central para projetos, portfólio, conhecimento, políticas e coordenação. |
| Evolution Node | Runtime local/privado que observa e age em um projeto com autonomia independente. |
| Module | Pacote instalável que oferece sensores, análises, skills, políticas, UI ou executores. |
| Sensor | Coletor que transforma uma fonte interna ou externa em observações normalizadas. |
| Evidence | Registro imutável ou versionado que sustenta uma claim. |
| Claim | Afirmação extraída ou derivada de uma ou mais evidências. |
| Signal | Mudança ou condição potencialmente relevante ainda não contextualizada. |
| Finding | Condição detectada e ligada ao estado real de um projeto. |
| Evolution Proposal | Caso de mudança completo: evidência, impacto, alternativas, plano e validação. |
| Decision | Aceite, rejeição, adiamento ou pedido de investigação sobre uma proposta. |
| Evolution Cycle | Observe → Understand → Challenge → Propose → Decide → Execute → Verify → Learn. |
| Baseline | Estado ou conjunto de políticas atualmente aceito. |
| Fitness Function | Verificação automatizada de uma característica arquitetural ou operacional. |
| Review Trigger | Condição explícita que exige reavaliar uma decisão. |
| Campaign | Conjunto coordenado de propostas semelhantes em vários projetos. |
| Harness | Instruções, skills, tools, MCPs, hooks, memória, sandbox, evals e políticas ao redor de um agente. |
| Skill | Conhecimento procedimental ativado sob demanda por um agente. |
| MCP | Protocolo para expor tools, resources e prompts de sistemas externos a aplicações de IA. |
| A2A | Protocolo para comunicação entre aplicações agentic independentes. |
| Capability | Ação abstrata autorizável, como `repo.read`, `issue.create` ou `experiment.run`. |
| Autonomy Level | Limite máximo de ações que o sistema pode executar sem nova aprovação. |
| Evidence Lineage | Cadeia de origem e transformações entre fonte, claim, finding e proposta. |
| Confidence | Grau de confiança calculado e decomponível; não sinônimo de probabilidade matemática. |
| Project Relevance | Compatibilidade entre um sinal e objetivos, restrições, estado e horizonte do projeto. |
| Evolution Debt | Diferença acumulada entre o estado atual e o estado justificadamente desejado. |
| Cognitive Debt | Distância entre implementação e entendimento compartilhado do sistema. |
